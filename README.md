# 명말 · 협객행 —— 갑신 1644

> 대사장궐(넘어지려는), 산하파쇄(산하가 깨어지는). 일검(한 자루 검), 일사(한 페이지 역사), 일강호(한 무렵 강호).

**명말 갑신지변(1644)**을 배경으로 한 웹 오픈월드 2D 액션 게임. 그대는 一名 유협 — 대명을 구하지는 못하지만, **증언**할 수 있다.

순수 HTML5 Canvas + JavaScript 구현, **의존성 0, 빌드 0**, 열자마자 플레이.

## 라이브 데모

GitHub Pages: https://sigco3111.github.io/mingmo-game-korea/

## 조작법

| 키 | 기능 |
| --- | --- |
| W A S D | 강호 行走 |
| 마우스 좌클릭 / J | 검 휘두르기 (마우스 방향으로 검기 발사) |
| 스페이스 / K | 경공 회피 (내력 소모, 잠시 무적) |
| Q | 필살기 · 만검귀종 |
| E | 대화 / 상호작용 |
| T | 명말 대사 타임라인 (1627–1662) |
| L | 사적잔권 (천하에 흩어진 실제 사료) |
| M | 음소거 |
| Esc | 일시정지 |

## 콘텐츠

- **오픈월드**: 경사(베이징), 매산, 류가장, 난민진, 대순군영, 초토촌, 산해관, 파효사 등 9개 거점 자유 탐험, 도로 연결, 주야 교체, 비/눈/재 3종 날씨.
- **메인 스토리**: 난세 부평초 → 검경지환 → 한 끼의 은혜 → **갑신지변 (매산에서 숭정제 殉국 목격)** → 산해관 밖 청병 격퇴 → 청사여진.
- **역사 증언 시스템**: 지도 곳곳에 8권 실제 사료 — 《명사 · 유적전》, 숭정 遺詔, 《갑신전신록》, 史可法 《복다르곤서》, 《양주십일기》, 오삼계 《乞師書》, "迎闯王不纳粮" 민요, 담천 《국작》.
- **역사 인물 대화**: 이야기꾼, 늙은 난민, 난민 부인, 유방승, 금의위 밀정, 대순군 노병(은천 역졸 출신), 관녕군 초관 — 각자 사료 기반 대사.
- **전투**: 검기 탄도 + 근접 호, 경공 회피, 필살기 AOE, 유구/유구 두목/청병 예졸/청병 궁수 4종 적, 경험치 레벨업, 드롭, 화면 진동, 핏자국.
- **수묵화 다크 UI**: 해서체 금자, 재 떨림 타이틀, 원형 미니맵, 스킬 쿨다운, 임무 트래커, 타임라인 수기.

## 로컬 실행

빌드 필요 없음, 브라우저로 `index.html` 열기:

```bash
npx serve .
```

## 기술

- 순수 Canvas 2D 렌더 (모든 미술 프로그래밍 생성, 외부 자원 없음)
- WebAudio 합성 효과음 (오디오 파일 없음)
- 시드화 랜덤 월드 생성, Y 정렬 깊이 드로잉, 저해상도 도로/핏자국 영구 레이어
- localStorage 저장 (임무 / 잔권 / 경지)
